### 📂 What's in here

```
$ ls DS-in-c/
array.c        → array operations, implemented from scratch
linklist.c     → singly linked list, implemented from scratch
```

A growing collection of **core data structures implemented in pure C** — no libraries, no shortcuts. Written to actually understand what's happening under the hood, not just call a built-in function.

### ⚙️ Run it yourself

```bash
git clone https://github.com/MALIK25252007/DS-in-c.git
cd DS-in-c

gcc array.c -o array
./array

gcc linklist.c -o linklist
./linklist
```

---

### 🧠 Why this repo exists

Most tutorials show data structures with pre-built functions. This repo is the opposite — every insert, delete, traverse, and search is written manually to build real intuition for how memory, pointers, and structure actually work in C.
